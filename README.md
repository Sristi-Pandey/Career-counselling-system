# Career Counselling System

A rule-based career counselling application developed using Python as part of my Class XII Computer Science holiday homework.

## About the Project

This project collects information about a user's academic strengths, interests, career preferences, and other relevant details through an interactive questionnaire. Based on selected responses, it suggests potential career paths and provides general information about educational pathways and job-market trends.

## Features

* Interactive, menu-driven questionnaire
* Career suggestions based on rule-based logic
* Educational pathway recommendations
* General job-market insights
* Input validation for unanswered questions
* File handling to store questionnaire responses

## Technologies Used

* Python

## Python Concepts Applied

* Functions
* Conditional statements
* Loops
* Dictionaries
* String handling
* User input and validation
* File handling

## Learning Outcomes

Through this project, I gained practical experience in structuring a Python program, working with user input, implementing conditional logic, and storing data in a text file. It helped me understand how programming can be used to address a real-world problem.

## Note

This project provides basic, rule-based suggestions for educational purposes. Its recommendations are not a substitute for professional career counselling.
